# AIKON-demo frontend

AIKON-demo's frontend is a web application connected to a PostgreSQL database, with Svelte components. It interacts with AIKON-API.

In `dev` mode, the Django frontend runs on the host, while PostgreSQL and Redis are dockerized. In `local` and `prod` modes, the Django app itself is dockerized.

To install and use, refer to [the main README](./../README.md).
